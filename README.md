# Diwali Festival Sales Analysis

## Problem Statement
Retail businesses make inventory and marketing decisions 
based on gut feeling during festival season — resulting in 
wrong stock and wasted marketing budget.

## Objective
Identify who buys what, from where, and how much during 
Diwali to enable data-driven marketing and inventory strategy.

## Tools Used
- Python — Pandas, NumPy, Matplotlib, Seaborn

## Key Findings
- Core buyer — Married women aged 26-35
- Top states — UP, Maharashtra, Karnataka
- Top categories — Food, Clothing, Electronics
- Top professions — IT, Healthcare, Aviation

## Project Documents
- PRD — Product Requirement Document
- Workflow Diagram

## Business Recommendation
Focus 70% of Diwali marketing budget on identified 
persona and top 3 states for maximum ROI.
